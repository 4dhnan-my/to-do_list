# Tempo AI Planner

A premium AI-powered to-do list, weekly calendar, analytics, and smart reminder web app built with React, Vite, Tailwind CSS, Framer Motion, and LocalStorage.

## Features

- Add, edit, delete, complete, search, filter, and reorder tasks
- Categories, tags, priorities, due dates, due times, subtasks, and notes
- Natural language input such as `Meeting tomorrow at 4 PM`
- Smart priority, task breakdown, daily planner, productivity tips, and scheduling recommendations
- 7-day weekly calendar with day, week, and agenda views
- Drag tasks between days, hourly slots, today highlight, current-time indicator, mini month widget
- Smart reminders with browser notifications, popup modal, snooze, repeat rules, sound and vibration options
- Dashboard, Tasks, Completed, Weekly Calendar, Analytics, Reminders, and Settings/Profile
- Dark/light theme, onboarding, mobile bottom navigation, PWA/offline service worker
- Export/import JSON and reset all data

## Install

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, usually `http://127.0.0.1:5173`.

## Build

```bash
npm run build
npm run preview
```
